Power-Up Architecture & Entrypoints

All multi-page HTML and script endpoints registered for Trello Power-Up capabilities:

🔗 /auth.html
The Process Power-Up authorization screen. Handles popup OAuth, origin security checks, and member-scoped token persistence.
⚡ /authorized.html
Trello OAuth return page. Receives #token=... and posts it safely back to the opener via process-powerup-auth postMessage.
⚙️ /settings.html
Displays the currently authenticated Trello member profile and allows token disconnect / re-authorization.
🔌 /powerup.html
The main Power-Up connector script initializing capabilities: authorization-status, show-authorization, show-settings, board-buttons, card-buttons, and card-badges.
